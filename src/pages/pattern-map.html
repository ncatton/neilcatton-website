The same handful of structural failures, traced wherever they've shown up across {{years.words}} years and more than twenty sectors — each one linked back to where it was written about, and to the card that gives you something to do about it, where one exists.

These aren't a list of unrelated observations. They're the same small set of structural failures, recurring under different names in different industries — the same mechanism that fails a fraud victim in banking also fails a patient in the NHS, and a candidate applying for a job. Seeing the pattern is the first step; the sector instances below are the evidence, not the argument.

Built from what's actually been published, not from theory. Some patterns already have a Practice Library card attached — something you can act on. Others don't, because not every pattern resolves into a checklist. Recognising the shape of a problem is not the same as fixing it, and this map doesn't pretend otherwise.
